- 数据源：500彩票网（当前唯一来源，每日自动更新）

- A 策略（均衡统计）/ B 策略（冷热组合）/ C 策略（纯随机）→ 生成下一期娱乐推荐

## 二、未来升级方向记录

### 方向 1（v1.4）：多数据源架构

未来考虑增加第二、第三数据源，例如：
- 官方开奖数据
- 新浪彩票
- 网易彩票
- 其他历史数据库

**目标**：不是立即接入，而是先建立架构：

```
数据源 A
   ↓
数据验证
   ↓
数据源 B
   ↓
异常检测
   ↓
最终数据库
```

**硬性要求**：任何新增数据源必须：
- 验证开奖期号
- 验证红蓝号码
- 防止错误覆盖

### 方向 2（v1.5）：专业走势图

当前：1000 期号码轨迹。未来增强：

**前区走势图**
- 每个号码出现轨迹
- 连续遗漏
- 出现频率
- 热度变化

**后区走势图**
- 蓝球冷热
- 奇偶趋势
- 大小趋势

**时间维度**：最近 50 期 / 最近 100 期 / 最近 300 期 / 最近 1000 期
→ 形成类似专业彩票走势图。

### 方向 3（v1.6）：综合推荐模型

当前：固定 A/B/C 策略。未来增加**综合评分模型**：
- 号码评分 = 历史频率 + 近期热度 + 遗漏周期 + 冷热平衡 + 组合概率
- 生成：**综合推荐 TOP10**

⚠️ 必须定位「娱乐分析」，不是预测。

### 方向 4（v1.7）：达人推荐数据融合（重点记录）

未来考虑采集公开推荐信息（彩票达人推荐 / 彩票论坛推荐 / 公开文章推荐），**不是直接相信**。流程：

```
达人推荐数据
   ↓
号码统计
   ↓
出现次数排行
   ↓
与历史模型结合
   ↓
综合娱乐推荐
```

输出示例：
```
本期热门推荐号码：12 16 19 28 33
来源：
  历史模型：12 出现概率较高
  达人推荐：12 被 15 个来源推荐
```

### 方向 5（v1.8）：个人选号（用户互动）

**手动选号**
- 用户选择：前区 5 个号码（如 01 05 12 20 33）+ 后区 2 个号码（如 03 09）
- 系统分析：历史出现次数 / 最近遗漏 / 组合情况
- 输出：**你的号码历史表现分析**

**机选推荐**
- 普通机选：随机生成
- 智能机选：根据冷热比例 / 奇偶比例 / 大小比例生成

## 四、当前开发原则（以后升级必须遵守）

1. 不影响当前稳定自动运行系统
2. 新功能优先独立模块
3. 尽量不修改核心数据流程
4. 前端展示优先独立页面
5. 所有数据必须来自真实开奖数据
6. 所有推荐必须标注「娱乐分析」
