## 〇、结论摘要

当前趋势页（trend-v2）为「HTML 表格 + 圆点 + 简单连线」，产品效果未达预期。本设计将其重构为 **SVG 驱动的数据分析可视化模块**：号码轨迹图（语义化连线）、遗漏趋势、热冷矩阵、和值跨度、奇偶大小五大视图，统一筛选与 hover 详情，零依赖、不影响 workflow、数据全部来自现有 `dlt_history.json`，并为双色球/3D/快乐8 提供参数化复用边界。

---

## 一、产品目标

1. **可读**：一眼看清号码出现轨迹、遗漏状态、热冷分布，告别 35×N 的密集格子；
2. **可量化**：每个状态有数字（出现次数/当前遗漏/最大遗漏/平均遗漏/热度等级）；
3. **可探索**：期段 × 分组 × 指标 tab 自由组合，hover 即时详情；
4. **有语义**：连线表达重号/斜连/趋势关系，非装饰；
5. **可复用**：数据计算与 SVG 渲染解耦，号码规则参数化，对齐 Task 17.0 平台模板目标。

## 二、页面结构

```
┌ 顶部筛选区 ──────────────────────────────────────────────┐
│ 期段：10/30/50/100/300/1000 │ 分组：前区/后区 │ 重置       │
│ 指标 tab：轨迹 / 遗漏 / 热冷矩阵 / 和值跨度 / 奇偶大小     │
├ 主趋势图区（SVG 画布，按 tab 切换视图）───────────────────┤
├ 数据说明区（图例 / 数据口径 / 更新时间 / 免责声明）────────┤
└ 交互区（hover 浮层 / 图例开关 / 视图重置）─────────────────┘
```

- 所有视图共享「期段 + 分组」选择，切换即时联动；
- 大屏默认 ≥300 期，移动端横向滚动（保留 `.trend-scroll` 模式）；
- 现有概览卡与时间范围卡并入顶部筛选区，减少纵向滚动。

## 三、功能模块设计

### 3.1 号码出现轨迹图（主视图）
- **坐标**：横轴期号（时间），纵轴号码（01-35 / 01-12）；
- **节点**：SVG `<circle>` + `<text>`（号码），保留 G-1 号码文本；
- **连线语义**：
  | 连线 | 语义 | 视觉 |
  | --- | --- | --- |
  | 重号连线 | 同一号码连续两期出现 | 实线（组色），可开关 |
  | 斜连连线 | 相邻期号码差=1 | 虚线弱化，可开关 |
- **遗漏底色**：行背景按当前遗漏 miss-lv0-4 色阶（SVG `<rect>`）；
- **期号轴**：刻度每 5/10 期显示，hover 显示完整期号+日期。

### 3.2 遗漏趋势图
- 每号双条对比：**当前遗漏 vs 历史最大遗漏**（数值标注）；
- 平均遗漏列表（复用 `calculateMissing.avg`）；
- 顶部当前遗漏 TOP 排行（横向条形）。

### 3.3 热冷分析矩阵
- 当前 N 期按每 10 期一段切片 → 号码×期段热力图（出现次数色阶）；
- 最近段 vs 前一段冷热变化（↑/↓）；
- 热度三分位（热/中/冷）图例。

### 3.4 和值 / 跨度趋势图
- 每期前区和值折线 + 历史 p25-p75 参考带 + 当前期标注；
- 跨度同理；数据来自新增纯函数 `calculateSumSpan`（与后端 `analyze_sum_span` 契约一致）。

### 3.5 奇偶 / 大小趋势
- 现有比率条形升级为**每期比率折线 + 平均参考线**（前后区可选）。

### 3.6 hover 详情（统一浮层）
```
第 26093 期 · 2026-08-17
号码 22（前区）｜ 热度 🔥
出现 52 次 ｜ 当前遗漏 3 期 ｜ 最大遗漏 14 期 ｜ 平均遗漏 6.2 期
该期开奖：前区 08 10 22 26 29 · 后区 03 10
```

## 四、数据结构设计

### 4.1 现有数据（不改动）

**dlt_history.json**
```json
{ "updated_at": "…", "source": "500", "count": 1000,
  "issues": [ { "issue": "26093", "date": "2026-08-17",
                "front": [8,10,22,26,29], "back": [3,10] } ] }
```

**后端 analyze() 输出**（口径参照，本轮不改）：freq / hot / cold / cur_omit / max_omit / oddEven / bigSmall / consec / zone。

### 4.2 前端计算数据契约（新增纯函数产出，统一供 SVG 渲染）

```js
// 轨迹视图输入（buildMatrices 演进）
{
  groups: { front: {labels:[1..35], issues, hits: bool[35][N]},
            back:  {labels:[1..12], issues, hits: bool[12][N]} },
  perNumber: { num, count, curOmit, maxOmit, avgOmit, heatTier }  // calculateHot+Missing 合并
}

// 热冷矩阵
{ num, segments: [ {start, end, count}, ... ], delta: +1/-1/0 }

// 和值/跨度（calculateSumSpan，契约对齐后端）
{
  front_sum:  { p25, p75, mean, series: [ {issue, date, value} ] },
  front_span: { p25, p75, series: [...] },
  back_span:  { p25, p75, series: [...] }
}

// 奇偶/大小比率
{ issue, date, oddRatio, bigRatio }
```

### 4.3 视图渲染器统一接口

```js
renderTrajectory(el, data, opts)   // SVG：节点/连线/底色/期号轴
renderMissing(el, data, opts)      // HTML 双条对比表 + 排行
renderHeatmap(el, data, opts)      // SVG rect 热力图
renderSumSpan(el, data, opts)      // SVG polyline + 参考带
renderRatio(el, data, opts)        // SVG 折线
bindHover(el, lookup)              // 统一 hover 浮层（复用 G-1 事件委托）
```

## 五、技术实现方案

| 维度 | 方案 |
| --- | --- |
| 渲染 | **SVG 为主**（轨迹/热力/折线），HTML 表格仅用于统计列表；零第三方库 |
| 数据 | `data/dlt_history.json` 前端即时计算；D1 `/api/issues?range=all` 作为未来长历史通道（本轮不启用） |
| 新增 JSON | **不需要** |
| workflow 影响 | **无**（纯前端重构 trend-v2 三文件，可拆 `trend-v2-views.js`） |
| 交互 | 事件委托单 listener + fixed 浮层（复用 G-1 模式） |
| 性能 | 默认 ≤300 期直渲；1000 期 3.5 万节点可承受，卡顿则期号轴降采样 |

## 七、双色球 / 3D / 快乐 8 模板化扩展方案

**核心原则：数据计算与 SVG 渲染解耦，号码规则参数化（对齐 Task 17.0 `lottery_rule`）。**

| 彩票 | 组模型 | 复用方式 | 特殊适配 |
| --- | --- | --- | --- |
| 双色球 | 6+1 双组 | **同构直接复用** | 后区取 1；组参数（count 6/1、min/max 1-33/1-16）由 `lottery_ssc.yaml` 驱动 |
| 福彩 3D | 单组 3 位（positional） | 计算与渲染组件复用 | 轨迹按「位」拆分（百/十/个）渲染；热冷/遗漏按位计算；`positional:true` 分支 |
| 快乐 8 | 20/80 单组大池 | 组件复用 | 纵轴 80 行（性能评估）；期段热力复用；出现 20 个/期 → 密度高，连线语义改为「遗漏回填」为主 |

**扩展入口**：视图渲染器接受「组定义」参数（`{key, min, max, count, positional}`），新增彩票只需提供规则配置，无需重写视图。
