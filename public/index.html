产品介绍

本助手基于 500 彩票网公开的历史开奖数据，做纯统计维度的娱乐分析，帮助彩民从频率视角观察大乐透，不提供任何中奖预测。

  • 数据：每日由 GitHub Actions 自动抓取并统计（前区 1–35 / 后区 1–12）
  • 分析：热号冷号、奇偶大小、连号等统计指标
  • 推荐：本期智能推荐（综合评分模型），基于历史数据统计的娱乐产物，非预测
  • 展示：Cloudflare Pages 静态托管，全部代码开源可查

所有结论均来自历史数据的频率统计，仅供娱乐参考。
